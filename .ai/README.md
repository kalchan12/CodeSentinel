# CodeSentinel AI Project Context

This directory contains the shared project context used by AI coding
agents and developers.

## Authority

-   `PROJECT.md` --- what CodeSentinel is and its scope.
-   `ARCHITECTURE.md` --- how the system is structured and which
    technologies/boundaries it uses.
-   `PLAN.md` --- the ordered, living development plan.
-   `DESIGN.md` --- UI/UX and HCI design system.
-   `AGENTS.md` --- rules and workflow for AI coding agents.
-   `SECURITY.md` --- security engineering constraints and threat
    boundaries.
-   `DECISIONS.md` --- significant technical decisions and their
    rationale.
-   `SKILLS.md` --- skill/tool/dependency discovery rules.
-   `SUGGESTIONS.md` --- ideas that are not approved work.

`PLAN.md` is the only source for what should be worked on next. These
documents must stay concise and consistent with the repository.
