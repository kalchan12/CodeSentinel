# Capstone research notes

Placeholder for the capstone team's research library. Suggested topics:

- **Static analysis tooling** — how Semgrep rules and JSON output map onto
  the `Finding` contract; rule performance and false-positive rates.
- **Secrets detection** — Gitleaks vs regex-based heuristics; entropy-based
  detection; avoiding false positives on tests/sample data.
- **Dependency risk** — OSV format, vuln feeds, ECLIPSE of offline
  databases for local-first operation.
- **Tree-sitter** — AST patterns vs regex for detection accuracy.
- **Risk scoring** — CVSS base/vector equations, weighted models, industry
  scoring (DREAD) and how to keep scoring explainable.
- **Local AI models** — open-weight models that run on modest hardware,
  prompt engineering for security analysis, cost/quality trade-offs,
  privacy guarantees for local-first analysis.
